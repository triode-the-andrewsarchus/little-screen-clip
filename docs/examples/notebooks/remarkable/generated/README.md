# Derived archive fixtures

Generated by `scripts/notebook_remarkable_fixtures.py` from the retained licensed
originals. These are deliberately derived containers, not unmodified tablet/RCU
exports or independent tablet image references. Source notices remain in
`../archives/LICENSE` and `../legacy-real/Cargo.toml.upstream` / README.

- `layered-template.rmn` repackages the two real v6 pages from `archives/Test.rmdoc`
  into a plain TAR notebook archive. It changes template references to a nested
  RMT containing our own warm-colored grid SVG. The RMT's filename differs from
  its JSON `fileName` to exercise actual template identity resolution.
- `raster-template.rmn` uses the same real v6 ink over our own pale-blue PNG
  template, exercising an RMT without an SVG member.
- `redirected-pdf.rmdoc` retains the same real ink, adds our own deterministic
  two-page PDF with clearly different background colors, reverses source PDF
  page references, and adds an intentionally empty inserted page. This tests
  redirection, compositing, missing annotation records and page counts.
- `legacy-paper.rmn` packages the two retained real v5 handwriting pages in
  reverse filename order. Legacy `.pagedata` supplies the first page's nested
  grid template while the second page is explicitly blank paper.

Our SVG/PDF backgrounds are authored test artwork under the project's license;
they are not copies of tablet factory templates. The archive layouts follow
RCU's documented RMN/RMT formats. Deterministic source IDs and colors make page
order and background mistakes observable without reproducing the renderer's
output as a reference.
