# System preview conformance

## Scope and status

This is the current reconciliation of `dev_and_sys_file_manager_spec.md`. The chronological [requirement audit](System%20Preview%20Requirement%20Audit.md) retains discoveries, failed attempts and their later corrections; its early Partial entries are not the current task list. The implementation tracker retains the development history.

**Complete for the approved initial implementation.** Every named family and shared acceptance requirement has an inspected implementation/evidence mapping below. The final serial workspace, formatting, release-build, private directory/navigation and scoped syscall gates pass. No required implementation or acceptance item remains open. No commit is authorized by this audit.

The spec's injectable-fixture/read-only-hardware strategy applies throughout. Optional device-opening queries, route/neighbor-table viewers, historical metrics and unavailable hardware permutations are not additional initial requirements. A failed or unavailable observation is never evidence that a feature/state is absent.

## Directory and relationship reconciliation

- `/dev/pts` counts numeric same-mount slave interfaces, excludes PTMX and shares throttled process associations. `/dev/disk` and `/dev/serial` group resolved target identities while retaining distinct aliases; broken/non-device targets and caps remain explicit.
- `/dev/dri`, sound, input, CPU, raw USB, VFIO and mapper summaries reuse registered object roles and existing family collectors. GPU connectors read status only; CPU CPUID/MSR nodes remain unopened; VFIO and mapper retain actual members/dependencies rather than inferring groups from filenames.
- Named sysfs roots match known object identity. Bus/class inventories count bounded observed registration names; major/minor lookup links verify actual access-node identities. Generic device children require direct subsystem registration and matching hierarchy context, excluding attribute directories and aliases.
- Relationship navigation retains parent/child, driver/subsystem/class/access, holder/slave, IOMMU, physical, firmware and power-owner distinctions. Ordinary backing files/mounts browse/reveal; kernel objects inspect. Captured origin/target identity and relevant namespace/mount/process lifetime are revalidated off the UI thread before accepting navigation. Directory double-click still browses normally.
- Current directory/identity/source/failure/cap/alias tests are in the 354-system-test gate. Fresh GPU/sound/input private checks pass eight observations each in `/tmp/system-final-registered-directories-{dark,light}/report.json`; reviewed screenshots show readable actual counts/connector states and explicit process coverage. Earlier PTY/alias/CPU/USB/VFIO/mapper reports remain named in the chronological audit.

## Verification and limits

Fresh navigation checks pass **18 observations in each appearance** (`/tmp/system-final-navigation-{dark,light}/report.json`); both inspector screenshots were reviewed. They complement the eight directory checks per appearance and three read-routing checks, summarized in `/tmp/system-final-conformance-artifacts.json`. All four private application runs exit successfully. Final `cargo test --workspace -- --test-threads=1` passes **2,361 tests, zero failed, 23 ignored**, across 26 suite results (`/tmp/system-final-conformance-workspace-tests.log`). `cargo fmt --all --check` passes (`/tmp/system-final-conformance-format.log`). Both release desktop binaries build successfully with `cargo build --release -p clip-workbench --bin clip-workbench --bin clip-file-manager` (`/tmp/system-final-conformance-release-build.log`, up to date in 0.24 seconds). Documentation-only reconciliation has not changed production code since the focused-sensor gate; the release build confirms the UI checks used the current binaries. `git diff --check` passes. All processes started for these final gates are terminal.

Known limits are explicit rather than claimed successes:

- Hardware absent on this host uses deterministic injected/temporary fixtures; no bus probes, flash scans or hardware faults were manufactured.
- Optional termios/V4L2/device-opening capabilities beyond explicit VCS capture remain optional. Privileged fields stay unavailable under current permissions.
- The private environment has no usable Vulkan adapter for Gaussian rendering. Ordinary regression runs record that exact capability error; no rendered Gaussian pixels are claimed. The renderer source was not changed for this feature.
- The earlier default-parallel workspace run had timing/shared-worker failures; the verified workspace gate uses `--test-threads=1`. Ignored tests and existing shared-source warnings are not counted as verified or clean Clippy.
- Real uninterruptible I/O is not induced. Controlled blocked/delayed children prove deadline, ownership, admission and shutdown behavior; OS-killed but not-yet-exited children remain counted.

No unrelated personal configuration is changed or committed by this reconciliation.
