# EDA file inspection and previews

Open a supported file in Files to inspect its metadata and preview. List strips and file cards use the same guarded decoders. Inspection reads ordinary files up to 32 MiB.

| Files | Preview and inspection | Limits |
| --- | --- | --- |
| Gerber `.gbr`, `.ger` | RS-274X and X2 artwork, units, coordinate format, polarity, aperture counts, file attributes and copper thickness when present. The raster composites dark and clear objects in order. | Content probing separates Gerber `.gbr` from GIMP brushes. The decoder reports unsupported aperture and image transforms. Solid rectangular apertures support legacy linear draws. Other nonstandard sweeps can be approximate. |
| Excellon `.drl`, `.xln` | Drill hits, slots and routed paths in millimeters, with tool diameters, coordinate format and counts from the plotted geometry. | Consecutive cut segments can form one routed path. Tool-up travel is excluded. Commands the flattener cannot interpret are reported. |
| Placement `.pos` | KiCad ASCII and column-qualified CSV or TSV. Inspect reference, package, side, position and rotation. Coordinates convert mm, inches or mils to millimeters. | The parser retains up to 200,000 placements. The viewer scrolls through all retained rows and uses the original placement when selecting a filtered row. |
| HPGL `.hpgl`, plotter `.plt` | Pen strokes, arcs, circles, labels and basic coordinate scaling in plotter units. | Polygon buffers stop a partial preview at `PM`, `EP` or `FP`. Filled rectangles and wedges show a disclosed outline approximation. Device-specific printing, advanced fills and printer containers are outside the preview. |
| KiCad board `.kicad_pcb` and footprint `.kicad_mod` | Board outline dimensions, declared stackup, layers, footprints, net counts, track lengths and basic copper, pad and drill geometry. Board net names can come from legacy declarations or KiCad 10 item records. | Board outline dimensions follow the edge centerlines. Inner copper is grouped. Padstack-specific copper, custom pad shapes and zone fills are simplified. Only a bounded list of net and footprint details is retained. |
| KiCad schematic `.kicad_sch` and symbol library `.kicad_sym` | Sheet title, symbols, wires, buses and labels. Preview uses the embedded symbol definitions and can show units from a local symbol library file. | Only the opened sheet or library is read. External library and hierarchy lookups stay outside the preview. |
| KiCad project `.kicad_pro` and Gerber Job `.gbrjob` | Project configuration or job metadata, including reported board dimensions, copper count, stackup materials, recorded colors and thicknesses, finish and file mapping. | The stackup diagram is schematic. Job paths are displayed as metadata. Optional fields depend on what the exporter wrote. |
| SPICE `.cir`, `.sp`, `.spice` | Title, top-level component and node counts, subcircuits, models and analysis directives. The thumbnail shows the component distribution. | Unsupported cards can leave a partial parser result. External includes remain metadata. The preview never runs the circuit or its control blocks. |
| SPICE and LTspice `.raw` | ASCII and binary waveforms, including LTspice little-endian mixed-precision, double, complex and single-plot FastAccess. The preview preserves original sample order and peaks within each sweep. | Positive waveform headers distinguish these from camera RAW. The preview retains up to 16 plots, 64 traces per plot and 4,096 samples per trace. Explicit dimensions or axis evidence identify sweep boundaries. Separate step-label logs stay outside the preview. Appended LTspice FastAccess plots are unsupported. |
| LTspice settings `.plt` | Analysis sections, pane layout and configured trace names. The thumbnail shows up to four panes from the first section with panes. | Waveform samples live in `.raw`. Plot expressions, annotations and layout beyond the basic pane summary stay in the source excerpt. |

## Parser choices and reference checks

- **Gerber and Excellon.** `lib_gerber_edit` handles both formats and supplies ordered geometry in millimeters, clear polarity, macro evaluation and flattening limits. MakerPnP's `gerber_viewer` provides Gerber rendering with optional egui integration. Retaining the dual-format flattener gives the same geometry and diagnostics to both the desktop viewer and the headless card renderer. The rectangular-draw test compares against a Gerber region with the same analytical boundary. [lib_gerber_edit](https://docs.rs/lib_gerber_edit/latest/lib_gerber_edit/) [gerber_viewer](https://github.com/MakerPnP/gerber-viewer)
- **HPGL.** `nom-hpgl` parses a command subset and leaves drawing semantics to the caller. The alpha `ezhpgl-core` interpreter has wider coverage, including polygons and clipping. Adopting it would replace the current pen travel, source-line interaction and cancellation integration. The current preview exposes its polygon and fill limits. [nom-hpgl](https://docs.rs/nom-hpgl/latest/nom_hpgl/) [ezhpgl](https://github.com/monozukuri-ai/ezhpgl) [HP reference manual](https://www.hp.com/ctg/Manual/bpl13211.pdf)
- **KiCad.** The existing `eda-view` S-expression parser and schematic scene renderer cover the read path. `kiutils_kicad` offers a typed, lossless document model and version diagnostics for editing. The preview already has the syntax tree and only needs a bounded projection of board geometry. KiCad 10.0.8 was used to upgrade a reference board and export a routed drill, copper Gerber and Gerber Job. The regression compares the slot endpoints and copper flash center to those exports. [eda-view](https://docs.rs/eda-view/latest/eda_view/) [kiutils-kicad](https://github.com/Milind220/kiutils-rs) [KiCad format notes](https://dev-docs.kicad.org/en/file-formats/sexpr-intro/)
- **SPICE.** `dune-netlist` supplies circuit elements and `dune-raw` handles SPICE3 and ngspice row-oriented data. The published `spice_rawfile` 0.0.1 crate has no decoder. Spicelib documents and reads the LTspice FastAccess column layout. The Rust preview reads those columns directly from the bounded payload and reuses the established sweep and peak reduction. Tests cover mixed precision, double, complex, stepped and truncated data, plus the binary operating-point output of an ngspice 47 resistor-divider run. [dune-raw](https://docs.rs/dune-raw/latest/dune_raw/) [spice_rawfile 0.0.1 source](https://docs.rs/crate/spice_rawfile/0.0.1/source/src/lib.rs) [PyLTSpice RAW File Structure](https://pyltspice.readthedocs.io/en/latest/varia/raw_file.html)
