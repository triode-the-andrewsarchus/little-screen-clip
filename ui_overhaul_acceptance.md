## Reproduction scenarios and fixture requirements

Keep fixture data under a local scratch directory unless a small deterministic generator is added to `scripts/`. Never place personal clipboard data or machine config in the repo.

Generate the available source-controlled fixture set with `python3 scripts/ui_acceptance_fixtures.py --output-dir /tmp/clip-ui-fixtures-<run-id>`. It creates Unicode/ANSI/Markdown text, 1,000-column and 20,000-row CSVs, binary insertion/deletion pairs, transparent PNG, stereo/silence/transient WAVs, a simple STL, a two-page PDF, a three-track MIDI file, a small RGB TIFF carrying Orientation and DateTime EXIF tags, and a basic SVG. It also creates four deterministic malformed inputs: `document-malformed.pdf` has a PDF header and synthetic catalog/page objects followed by an invalid cross-reference section; `music-malformed.mid` declares a six-byte MIDI header but ends after only the format field; `image-malformed.png` has a valid PNG signature and IHDR but a truncated IDAT chunk with no CRC or IEND; `text-invalid-utf8.txt` contains synthetic prose followed by invalid UTF-8 bytes `FF FE`. These malformed inputs target PDF structure parsing, MIDI header parsing, raster decoding, and strict text decoding error paths respectively. The PDF, MIDI, TIFF, SVG, and malformed binary inputs are assembled deterministically by the standard-library-only Python script; all fixture contents are synthetic and contain no personal data or metadata. The generator performs simple signature/structure checks and refuses to overwrite any named output fixture. Generation checks establish fixture shape only; no GUI error display or recovery result is claimed. Use `--large-audio-seconds 300` for a roughly 53 MB WAV that can expose delayed preview completion; the default is 30 seconds to keep routine runs fast.
